
# Pahana Edu Management System

Phana edu management system is a book shop customer management, inventory tracking, billing, and administrative functions management system.

### Key Features
- **Admin Management**: Secure admin registration and authentication.
- **Customer Management**: Complete CRUD operations for customer data.
- **Inventory Management**: Item creation, updating, and stock tracking.
- **Billing System**: Complex bill generation with inventory integration.
- **Dashboard Analytics**: Real-time data visualization.
- **Session Management**: Secure session handling and authorization.

### Business Domain
- **Target Users**: Small business owners and system administrators
- **Primary Functions**: customer management, resource tracking, financial operations
- **Scale**: Medium-scale shop management system

## 💻 Technology Stack

### Backend Technologies
- **Java 8**: Core programming language
- **Java Servlets**: Web request handling
- **JDBC**: Database connectivity
- **Maven**: Build automation and dependency management
- **JUnit 5**: Unit testing framework

### Frontend Technologies
- **HTML5**: Markup structure
- **CSS3 + Bootstrap 5**: Styling and responsive design
- **JavaScript + jQuery**: Client-side interactivity
- **Chart.js**: Data visualization

### Database
- **MySQL 8.0**: Relational database management
- **JDBC Driver**: Database connectivity
